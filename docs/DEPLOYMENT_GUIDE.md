# 同事的一键部署说明

这是完整的 Windows 本地程序，包括网页、采集脚本、监督器、分析入口及 Excel 导出，不是只有网页的演示。

1. 把 ZIP 解压到自己的固定目录；不要在压缩包内直接运行。Python 依赖随完整部署包提供；首次安装仍需联网安装 Windows 运行时、Playwright Chromium、AdsPower 和其浏览器内核，预留至少 8 GB 空间。建议使用D:\选品工作台等较短目录；安装绝对路径超过100字符会在读取公司配置和改变环境之前给出提示，请先移动到短目录。
2. 双击 `deploy.cmd`，或把目录/GitHub 链接发给自己的 Agent：**“按 DEPLOYMENT_GUIDE 执行 deploy.cmd，检查安装结果并打开本地网页；不要启动采集或付费分析。”**
3. 内部包默认不含真实公司配置。管理员可以私下提供 `company.local.json`，放到项目根目录；也可以提供“含公司配置”的内部包。安装时会显示本机导入确认，必须由当前使用者确认，Agent 不要代点确认。配置按当前 Windows 用户加密保存。已有配置且未提供新配置时保留原配置。
4. 安装成功会打开 `http://127.0.0.1:8765/`。以后双击 `start-web.cmd`。更新代码后，在任务停止状态运行 `restart-web.cmd`。

网页输入品类、Amazon 榜单前多少名、每关键词数量、TEMU 路数及 API key。生成并检查规则后再启动。TEMU 依次采集销量最高和最近上架，网页显示进度和异常。开始滚动采集前的验证码需人工完成；滚动采集中遇到验证码，保存断点并自动更换 session 后续采，新 session 开始滚动前的验证码仍需人工完成。第三层付费分析需要单独点击启动。

新品类自动生成统一同款标准：区分决定款式的主体结构、部件布局，以及允许变化的颜色、局部花纹和包装；第一层和第三层使用同一份标准。先查看网页生成的规则再运行。采集快照自动进入本地第一、二层，第三层仍由人点击启动。相似度只负责召回候选，最终同款由双边图片事实和身份规则决定；分析仍有一定误判，结果应按业务重要程度复核。

安装器检查 Windows、项目文件、磁盘和工具，自动补齐缺少或不兼容的 Python 3.12.10、Node.js 24.19.0、PowerShell 7.6.5、VC++ 运行库、Python/Node 依赖、Playwright Chromium、AdsPower 8.7.23、FlowerBrowser Firefox 153 内核和第二层图像模型。AdsPower 从官方历史版本页下载并核验数字签名；其他固定运行时也从官方来源下载并验签。无需复制原电脑的 Python、浏览器目录或本机配置文件。

网络按接收电脑的实际环境处理：已有代理、VPN 客户端或系统代理配置时先保留并检测，程序启动采集时按真实监听端口和协议选择出口，不使用原电脑 IP，也不写死 7890。多个可用出口由使用者选一次；只有 TUN 时沿用现有系统路由。未检测到客户端时自动安装 Clash Verge Rev，不自动导入订阅或改变系统代理、TUN、防火墙设置。明确配置为 DIRECT 时不安装代理客户端；自行管理网络的管理员也可使用 `deploy.cmd -SkipProxyClient`。

首次使用仍需本人完成 AdsPower 账号和代理订阅授权，并导入获授权的本机公司配置；缺授权会说明停在哪一步，不能算部署验收通过。软件安装和账号授权分别检查，安装程序不会复制原电脑密钥或模拟密码登录。

安装失败会恢复本次替换前的项目虚拟环境、Node 依赖、Agent 配置和已确认导入的公司配置。原采集数据、断点、Excel 不删除。旧环境备份及失败环境留在 `.deployment-backup/`；已安装的系统级 Python/Node 不卸载。可再次运行 `deploy.cmd`。脱敏状态记录在 `runtime/install-status.json`。不要把整个 runtime、日志或公司配置上传 GitHub。

无修改、无凭据读取的准备检查：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File install.ps1 -PreflightOnly`。

管理员需要含公司配置的包时：在 dist 目录双击 **“双击生成含公司配置的内部包.cmd”**，选择配置文件，核对对话框中的目标 ZIP 后确认。程序只生成新包，保留原包。此 ZIP 有公司凭据，只可私下发给获准同事。公开 GitHub 只上传“GitHub展示版.zip”的解压内容；它没有原仓库历史，上传前可自行初始化新 Git 仓库。

本机已完成四路小规模真实采集及增量接口验收。另一台干净电脑、所有品类、小时级稳定性尚未实机验收；安装成功表示环境检查通过，不表示网站永远不报错，也不表示同款判断已经达到全品类准确率。
