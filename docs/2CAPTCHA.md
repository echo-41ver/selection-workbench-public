## 配置与最少操作

1. 本支线经单独批准合入、部署后，展开工作台“自动验证码 · 2Captcha”。
2. 填入本人账号的真实 API Key，勾选启用，保存。已有 Key 留空可保留；关闭功能不删除 Key。
3. 在当前任务点继续；仍运行的 TEMU 采集器会在原页面下次检查时读取配置。

默认关闭且 Key 为空。无 Key 不导致部署失败，不会充值或购买套餐。
配置通过原本机网页的来源检查保护；Key 只送往本机服务、当前用户 DPAPI 和官方 HTTPS API。
Key 不通过命令行、URL界面、日志、状态响应或诊断输出回传。

私密公司配置可增加 `twocaptcha` 字段，示例见 `config/company.example.json`。
内部装包向导可读取本机单独加密配置并将其装入完整内部包。
新电脑解压后按原导入流程在接收 Windows 用户下重新加密；不搬运旧机器 DPAPI 文件。
公开筛选排除公司配置、runtime、数据库与加密文件，并识别嵌套 `twocaptcha.key`。

## 本次适配边界

| 页面/题型 | 本支线行为 |
| --- | --- |
| TEMU 首次打开、搜索、采集中、排序、加载更多、HTTP恢复观察时的验证码 | 保存原快照后统一进入自动解题；保留 session、代理、关键词、计数和采集断点 |
| 明确的文字图形码 | 一个可见验证码输入框、同表单一张验证码图片和一个提交按钮；截图仅截该图片，填入答案并点原提交按钮 |
| TEMU 三图块拖动拼图 | 同一验证码容器内明确的拖图提示、一个背景和恰好三个可拖动图片；按服务返回坐标缩放为浏览器坐标执行拖动 |
| TEMU连线、旋转、滑块、无法辨认控件的拼图、跨域 iframe、GeeTest、WAF 等 | 显示未适配，保留原页面和断点，不发送错误题型付费请求 |
| 登录墙、403/429、网络错误、浏览器控制失败 | 原有原因分类与恢复逻辑保留；仅在页面确实显示验证码时才走验证码处理 |

服务有某种题型的 API，不等于本程序已适配该网站所有变化。特别是 TEMU 三块拼图接口不能被当成所有滑块、旋转和连线接口。
文字码和三块拼图的连接/执行已用本地页面和模拟响应验证；真实网站、当前 DOM 样式及付费解题效果仍待用户配置 Key 后验证。

## 停止、费用与恢复

- 官方 Python SDK 固定为 `2captcha-python==2.1.2`。它是付费服务客户端，不是本地免费模型。
- SDK 的 `send/get_result` 分离调用。提交前落盘，任务编号、轮询期限与状态记录在安装目录 `runtime/captcha/tasks.sqlite3`。
- 同一浏览器、同一图片只提交一次。停止后保留编号；下次查询同一服务任务，不创建第二个任务。
- 模糊提交、网络中断导致是否提交未知时显示“提交结果未知”，保留预留额度；不自动重发可能收费的 POST。
- 等待默认180秒、每10秒轮询一次；传输设置连接5秒/读取15秒超时。超时或解题失败后本题不再付费重试。
- 每任务默认最多10个新问题，每题预算预留$0.01，任务预算阈值$0.10；同一任务的采集器共享持久记录。预留用尽或已观察到的账户余额减少达到预算阈值时停止新增提交。
- **费用限制的实际含义**：预留数值不是服务报价，余额变化也可能包含同账号其他用途。本地预算控制能限制提交次数和新增提交，不能承诺服务账单严格不超过阈值；最后一笔在途任务可能随后计费。严格账户费用上限需要用户在服务账号侧设定。本程序不虚构 API 支持单题最高报价参数。
- 答案交给页面前记为 APPLYING，停止/崩溃不会自动重复执行答案。图片改变则丢弃旧答案。
- API 返回答案后继续检查页面20秒，验证码消失且页面恢复可用后才记录网站放行。TEMU原流程再次检查关键词、排序和商品，随后恢复采集。
- 本机 Windows 后台进程负责全部请求、执行与恢复，不依赖 Codex 或聊天保持打开。
