# TEMU 2Captcha 接入支线

本支线已合入主线源码 `faaf0780a864de23d84e497a678cefea1a844450` 的采集程序。只修改独立支线，不替换主线安装、Release、正在运行的任务或电脑3。Amazon 保留原有后台采集方式，极鲸云保留包内接口授权，两处采集实现不改。

## 内部包自动部署

维护者把真实 Key 装入完整私密公司包的 `twocaptcha` 配置。接收者按原有 `deploy.cmd` 流程部署，程序在接收 Windows 用户下重新加密保存，有 Key 即自动启用。工作台不增加 Key 填写框、开关或配置接口。

后续装包自动沿用本机已保存的加密配置。公开模板 Key 为空；公司配置、真实 Key、DPAPI、会话和运行数据库均不进入源码或公开包。Key 不经命令行、URL、日志、状态响应或诊断输出回传。

## 解题流程

- 图片加载完成后先请求 API。文字码使用官方 Python SDK；TEMU 图形题使用 JSON V2 `TemuImageTask`，发送主图及实际数量的参考图，不再固定三个图块。
- 数量题及未识别交互题使用完整面板截图，包含标题、说明、底图、图块与按钮。传统 Line 和 Icon 使用原始作答主图，避免接口把顶部参考图自身当成目标；Icon 的参考图按页面显示顺序排列。服务坐标以提交主图左上角为原点；执行时按实际显示比例换算，点击补上参考图半宽和半高。
- 已识别 Line/拖动和 Icon/依次点击的控件可执行返回答案。其他能提取完整题图的题目也先请求 API，无法确定操作方式时保留答案和现场，转人工。无法取得完整题图时直接说明原因，不伪造图片请求。
- 空坐标、无法解题、等待超时或网站未放行时，页面显示需要人工处理，保留原浏览器、session、关键词和采集断点。
- API 有答案不等于网站通过。执行后继续观察20秒，验证码消失且页面可用才记为放行，再由主线检查关键词、排序和商品并继续采集。
- 主线独立验证码页的被动等待仅对 `captcha_` 指令放行；其他采集指令保留原等待行为。首次打开页面的拦截清理由主线完成，随后在原 session 恢复采集。

## 请求、费用与停止

不设应用侧金额预算和新题请求数量上限，旧配置中的 `max_requests`、`budget_usd`、`reserve_usd` 被忽略。同一浏览器的同一题仍只创建一次服务任务；后续查询已保存的任务编号。结果未知的 POST 不自动重发。

任务记录在 `runtime/captcha/tasks.sqlite3`，答案加密保存。默认等待180秒，每10秒轮询；HTTP 连接5秒、读取15秒超时。停止后保留任务编号和断点，答案执行前先领取，避免重启后重复操作。

服务收费与目标网站 HTTP 200 或实际通过没有绑定关系。只有观察到目标网站结果后才报告正确；退款由服务方判定，不能承诺失败一律不扣费。

原有两次历史数量题对照仍保留：底图返回空数组并报告$0.0012；补上初始图块后返回ERROR_CAPTCHA_UNSOLVABLE。尚无数量题自动通过案例。
